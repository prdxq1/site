# TOPSHOP — концепт магазина

Адаптивный одностраничный сайт на HTML, CSS и JavaScript. Без установки зависимостей и сборки. Вся графика встроена в HTML/JS; внешние ресурсы не требуются.

## Запуск

```sh
cd /workspace/site
python3 -m http.server 8000 --bind 0.0.0.0
```

## Возможности

Каталог из 8 товаров, фильтры категорий и новинок, поиск, сортировка цены, избранное, карточка с выбором размера, корзина с изменением количества. Корзина и избранное сохраняются в localStorage. Адаптивная верстка, управление с клавиатуры, поддержка prefers-reduced-motion.

Оформление заказа и подписка — демонстрационные: платежи не проводятся, email не отправляется.

Проверка синтаксиса: `node --check app.js`.
